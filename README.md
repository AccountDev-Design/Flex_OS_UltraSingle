# 🚀 Flex OS Ultra

**Flex OS Ultra** es un sistema operativo gráfico inspirado en Android, desarrollado desde cero para placas Arduino y ESP32.

## 📦 Versiones

| Versión | Placa | Estado |
|---------|--------|--------|
| 🟢 Flex OS UltraSingle | Arduino Mega 2560 | Disponible |
| 🔵 Flex OS Ultra | ESP32-P4 / ESP32-C6 | En desarrollo |

---

# 🟢 Flex OS UltraSingle (Arduino Mega)

Versión optimizada para el Arduino Mega 2560.

### Características

- 📱 Interfaz tipo Android
- 🎨 Animaciones optimizadas
- 🖌️ Paint
- 🧮 Calculadora
- 🕒 Reloj
- 📅 Calendario
- 🎮 Juegos
- 📝 Bloc de notas
- ⚡ Optimizado para 8 KB de RAM

### Hardware

- Arduino Mega 2560
- TFT Shield 3.5"
- Pantalla táctil resistiva

---

# 🔵 Flex OS Ultra (ESP32-P4/C6)

La versión más avanzada de Flex OS.

### Características

- 🪟 Ventanas múltiples
- 🖥️ Modo PC (DeX)
- 📷 Cámara
- 🌐 Navegador
- 📂 Administrador de archivos
- 🎨 Paint avanzado
- 🎮 Juegos
- 💻 IDE integrado
- 📡 OTA
- 🚀 Muchísimo más rápida

### Hardware

- ESP32-P4
- ESP32-C6
- Pantalla IPS táctil
